Como usar no OBS da nuvem (IRLToolkit)

1. Clique em Copiar URL no overlay desejado.
2. No OBS remoto (neko), aperte Ctrl+Alt+Shift pra abrir o painel de colar, cole a URL, e aperte Ctrl+Alt+Shift de novo pra fechar.
3. Adicione um Browser Source e cole a URL. Defina largura/altura iguais à sua live (ex: 1920×1080).
4. Ao atualizar um overlay aqui, no OBS clique com o botão direito no source → Refresh cache of current page.
Dica: pré-visualização instantânea O botão Prévia abre o overlay direto do seu PC (sem esperar o GitHub) — bom pra conferir o visual antes de mandar pro OBS. A URL do GitHub pode levar ~1 min pra atualizar após publicar.
